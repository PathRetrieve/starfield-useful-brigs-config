## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Guard Behavior** | Configure guard aggression and patrol settings for brig areas |
| **Detention Rules** | Set maximum detention time and release condition triggers |
| **Interrogation** | Adjust information extraction success chances and failure outcomes |
| **Faction Config** | Configure brig behavior settings per faction independently |
